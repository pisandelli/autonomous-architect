## 4. 💾 Data Modeling (Draft Prisma Schema)
Define main entities. It doesn't need to be perfect Prisma syntax, but must show relationships.

```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  role      Role     @default(USER)
  posts     Post[]
}

model Post {
  id        String   @id @default(cuid())
  title     String
  authorId  String
  author    User     @relation(fields: [authorId], references: [id])
}
```
